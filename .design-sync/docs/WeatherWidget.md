# WeatherWidget

Самостоятельный блок погоды Шымбулака для верха главной. Пропсов не принимает, данные Tomorrow.io грузит сам. Сверху вниз:

- шапка: иконка погоды, крупная тонкая температура (`text-4xl sm:text-5xl font-extralight`) и «Ощущается N°»;
- строка деталей через точку: ветер с поворотной стрелкой `WindCompass`, видимость, влажность, осадки, температура ночью и днём, УФ;
- необязательная голубая строка снега «❄ Идёт снег · Свежего N см за сутки · Ожидается N см»;
- необязательная янтарная строка предупреждений;
- горизонтально прокручиваемая полоса прогноза на 24 часа из `TimelineItem`.

Состояния: `WeatherPlaceholder` во время загрузки и текст «Погода недоступна» при ошибке.

**Данные.** Виджет ходит в API, только если нет свежего кэша. Вне приложения ключа API нет, и он показывает «Погода недоступна». Чтобы показать правдоподобные данные, до монтирования запишите `localStorage["tomorrowioData"] = JSON.stringify({ data, timestamp: Date.now() })`. Здесь `data` — ответ Tomorrow.io `/timelines` с таймлайнами `current`, `1h` и `1d` (полный пример — в превью WeatherWidget). Кэш живёт 6 часов.

Виджет сам центрируется по `sm:max-w-2xl`. Ставьте его на всю ширину над сеткой камер.

```jsx
<WeatherWidget />
```
