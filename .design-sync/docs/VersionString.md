# VersionString

Мелкая строка версии справа внизу, «ver: abc1234» (`text-xs`, подчёркивание при наведении): первые 7 символов SHA сборки, в локальной сборке — «ver: develop». В приложении клик по ней сбрасывает кэш погоды и куку баннера установки, затем перезагружает страницу. Это действие передаётся в `onClick`. Ставится последней на странице.

```jsx
<VersionString onClick={() => window.location.reload()} />
```
