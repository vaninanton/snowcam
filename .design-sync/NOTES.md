# design-sync: заметки по SnowCam

Синхронизация компонентов SnowCam в Claude Design (проект «SnowCam», id в `config.json`).

## Как устроено

- **Это приложение, а не библиотека**: `dist/` — сборка сайта, библиотечного входа нет. Бандл собирается из `.design-sync/entry.ts`: он переэкспортирует компоненты из `src/` (у них экспорт по умолчанию) под именами и добавляет помощники `cx` и `cameraGridCols`. Конвертер запускать с `--entry ./.design-sync/entry.ts --node-modules ./node_modules`.
- **Список компонентов задан явно** в `componentSrcMap`: `.d.ts`-дерева нет, автопоиск ничего не найдёт. Новый компонент добавляется в три места: `entry.ts`, `componentSrcMap`, `dtsPropsFor`.
- **Пропсы описаны вручную** в `dtsPropsFor`: в репозитории они типизированы прямо в сигнатуре (`{ camera }: { camera: Camera }`), и экстрактор отдаёт пустой `[key: string]: unknown`. При изменении пропсов компонента править `dtsPropsFor`.
- **CSS — заранее собранный Tailwind 4**, а не стили приложения. `.design-sync/tailwind.css` импортирует `src/style.css`, сканирует `src/` и `previews/`, добавляет тему целиком (`theme(static)`) и словарь утилит через `@source inline(...)`, чтобы агенту было из чего верстать. Красит `body` как `index.html` (`antialiased bg-slate-900 text-slate-400`). **Перед каждой сборкой конвертера** выполнить `buildCmd` из конфига: он пишет `.design-sync/.cache/tailwind.out.css` (это `cssEntry`). Без него сборка упадёт или возьмёт устаревший CSS. Итог около 180 КБ (23 КБ в gzip). Прозрачности на всех оттенках раздували CSS до 660 КБ, поэтому они оставлены точечно.
- **Описания компонентов** лежат в `.design-sync/docs/<Name>.md`, frontmatter `category` задаёт группу (Video / Weather / App).
- **Версия Playwright** должна соответствовать Chromium в `~/Library/Caches/ms-playwright`. На 2026-10-28 там `chromium-1248`, и подошёл `playwright@1.64.1` из `.ds-sync`.

## Превью

- `WeatherWidget`: сам ходит в Tomorrow.io, а ключа в бандле нет — без данных показал бы «Погода недоступна». Превью кладёт правдоподобный ответ в кэш `localStorage["tomorrowioData"]` с текущим `timestamp`. Времена в примере считаются от текущего часа, иначе полоса прогноза была бы пустой. Если поменяется формат кэша в `useWeather.ts` (ключ, `{data, timestamp}`, TTL), превью сломается.
- `AddToHomescreen`: баннер скрывается кукой `addToHomescreenCalled`. Превью сбрасывает её на уровне модуля. Иконку компонент берёт по абсолютному пути `/android-chrome-512x512.png`, которого в карточке нет, поэтому превью подменяет `src` на `public/android-chrome-192x192.png`. Баннер `fixed`: обёртке дан `transform: translateZ(0)`, иначе он прижимается к окну, а не к карточке. У карточки свой отступ сверху около 24px, поэтому обёртка 200px при окне `720x260`.
- `HlsVideo` / `CameraVideo`: «живые» истории грузят реальные потоки `ipcam.kz`, кадр на скриншоте каждый раз разный, это нормально. Недоступное состояние — `src` на `ds-preview.invalid`.
- Постеры подключаются из `public/previews/*.webp` и встраиваются data URL. Если постер переименуют (имя — md5 содержимого), поправить импорты в `previews/HlsVideo.tsx` и `previews/CameraVideo.tsx`.
- `CameraVideo` → `Grid`: на ширине карточки `cameraGridCols(3)` даёт 2 колонки (брейкпоинт `lg` считается по окну). Это честная планшетная раскладка.

## Известные предупреждения валидации

- `[FONT_MISSING] "Cambria" (--font-serif)`: Cambria стоит в системной цепочке `--font-serif` из темы Tailwind (`theme(static)` выводит её целиком). Своих веб-шрифтов у приложения нет, оно на системном `font-sans`. Не баг.

## Риски при повторной синхронизации

- **Устаревший CSS**: забыли `buildCmd` перед сборкой — в бандле окажется старый Tailwind без новых классов.
- **`dtsPropsFor` дублирует типы из кода**: при изменении пропсов в `src/` контракт для агента тихо разойдётся с реальностью.
- **Данные в превью**: кэш погоды повторяет структуру `TimelinesResponse` и ключ `tomorrowioData`, а подмена иконки баннера зависит от пути `/android-chrome-512x512.png` в `AddToHomescreen.tsx`.
- **Сеть при захвате**: истории с живыми потоками зависят от доступности `ipcam.kz`. Если камера ляжет, «Live» покажет заглушку ошибки — оценку тогда не переносить вслепую.
- **Шапка `conventions.md`** перечисляет классы Tailwind. При урезании словаря в `tailwind.css` проверить их по `ds-bundle/_ds_bundle.css`.
